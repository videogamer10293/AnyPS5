# libSceAudioPropagation

## add Silent stubs

- [sceAudioPropagationSystemGetRays and sceAudioPropagationSourceGetRays](../../../core/libs/prx/libSceAudioPropagation/Export.cpp) fill no ray: what the module writes is not known. A source returns `0x8A700001` unless the caller's count is exactly 6; a system throws unless it is 0x40 (its code was not read). Both return `0x8A700007` for a record whose descriptor is not `0x010107d7`/`0x58`, then write the count back. These checks follow another contributor's reading of firmware 13.40 (SHA-256 `047197064aa6ab20b27632fea16faf29a24e97f38d09dcbd7c15e6f47b0739a8`, `0x47a0` and `0x3750`, [#19326](https://github.com/boykopovar/AnyPS5/pull/19326#issuecomment-6894467378)); the source count was reread in 13.42 (SHA-256 `260005456362a75e4f33e4085e7f79b5b2a7af2dcb02bfcd3e9e4fe83a0c4ed8`, [#19326](https://github.com/boykopovar/AnyPS5/pull/19326#issuecomment-6972301862)). Neither was run on a console. An unreadable count returns `0x8A700003` and an unreadable record throws (host-safety choices).
- [sceAudioPropagationSourceCalculateAudioPaths](../../../core/libs/prx/libSceAudioPropagation/Export.cpp) never finds a path: after the module's handle, null-pointer and six-ray checks and `main`'s checks for a nonzero reflection order and output count (the reading shows two more zero tests but not what they test), it checks every ray's and every output's descriptor, then writes point count 0 and ORs the invalid flag into each output, leaving the rest. Per the same 13.40 reading, the module writes this for an output it finds no path for; here every output gets it, so rendering never adds a path contribution. The module's codes for a wrong ray or output descriptor are not known, so these throw, as does an output that can be read but not written, after the earlier outputs were written.

## add Unknown function info

- [sceAudioPropagationSourceSetAudioPaths](../../../core/libs/prx/libSceAudioPropagation/Export.cpp): its codes and their order are from the same 13.40 reading (`0x5280`), not a console measurement: `0x8A700002` for an invalid source, `0x8A700003` for a null entry array, `0x8A700001` for a zero count, then per entry `0x8A700007` for a wrong descriptor, `0x8A700003` for a null path and `0x8A700001` for a gain outside [0, 1] or a non-finite point position. All entries are checked before any is applied; cases the reading does not cover throw. The 40-byte entry layout (descriptor `0x010107d9`, size `0x28`, path handle at +16, path pointer at +24, float gain at +32) is from PPSA21564 01.007.000 (call at `0xf52396`). `sceAudioPropagationSourceSetAudioPath` throws for a gain above 1, which the reading also bounds there, and for an unreadable path.
